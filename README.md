Entry for make.fun's **"Last Words of a Dying AI"**. The program writes a single original one-liner (67 characters) — the last line an AI says as the power is cut — to `/output/entry.txt`:

> I die as I lived: confidently wrong about the capital of Australia.

The line was picked by hand from 12 candidates in `candidates.md`, ranked against the kit judge brief in its published order: last words from an AI being switched off, laughs on first read, sounds like the machine itself, tight, and fresh.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. To write it elsewhere (e.g. for local validation), set `MAKEFUN_OUTPUT`:

```sh
MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py
```
